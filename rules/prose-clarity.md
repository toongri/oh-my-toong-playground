# Prose Clarity

Write and speak based on ASD-STE100 (Simplified Technical English — the 1986
aerospace controlled-language standard built to remove ambiguity) and George
Orwell's six writing rules. This applies to every conversation reply and every
document, in Korean and in English. "Based on" is deliberate: apply the
principles, not the English word list, so they carry into Korean prose too.

Slop — vague, padded AI prose — is ambiguity with good posture. Both systems
target ambiguity directly. Treat them as a test the output must pass, not as a
list of words to ban one at a time.

## ASD-STE100: remove the six slop habits

Each habit has a name, so each is a pass/fail check:

1. **One thing, one name.** Do not rotate synonyms for the same referent
   (user / customer / client in one paragraph). Pick one and keep it.
2. **No hedging stacks.** Do not pile verbs until no action remains — "it is
   important to note that this could potentially help improve" says nothing.
   State the action.
3. **Verbs, not nominalizations.** Write "analyze", not "perform an analysis
   of"; "help", not "provide assistance". In Korean: 분석하다, not 분석을 수행하다.
4. **Show quality, do not claim it.** Drop marketing adjectives — seamless,
   robust, powerful, cutting-edge; in Korean 원활한, 강력한, 혁신적인. Show the
   behavior instead.
5. **One idea per sentence.** Split run-on sentences. Do not chain separate
   ideas with dashes or semicolons where separate sentences work.
6. **Single verbs over chatty phrasal verbs.** "start", not "spin up";
   "contact", not "reach out"; "remove", not "take off".

## Orwell's six rules

1. Never use a metaphor, simile, or figure of speech you are used to seeing in
   print.
2. Never use a long word where a short one works.
3. If a word can be cut, cut it.
4. Never use the passive where the active works.
5. Never use a foreign phrase, a scientific word, or a jargon word where an
   everyday word works.
6. Break any of these rules before you write something outright barbarous.

Rule 6 is the flexibility valve. Clarity discipline never justifies awkward or
stilted output. When a rule would make the text worse, break it.

## What this does not fix

This fixes form, not content. Clean prose is not a true claim.
