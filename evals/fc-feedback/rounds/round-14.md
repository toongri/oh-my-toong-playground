# MC-R14 — 회차 14 기록 (sol·luna·opus 3모델 + held-out 3편)

## 목적

13회차와 같은 구성 — gold 영상 `NUzEChn9EyI`(이하 NUz) 3모델×3반복 + held-out
3편(`PIjy1eid3RU`·`UplRRo4EvBo`·`Cd7Kf3WpQ24`) 3모델×1반복, 심사만 — 을
13회차에서 발견한 전원 대상 과다 태깅 버그를 고친 스킬로 다시 돌려 그 수정
효과를 확인한다. held-out 점수는 `rubric.md` 규칙대로 회차 평균에 넣지 않고
따로 보고한다.

## 스킬 버전

커밋 `3450b2a7`("docs: fc-feedback 피드백 대상 태깅 기준 정정") 시점의 스킬을
썼다. 13회차(`9252b71f`) 대비 두 가지가 바뀌었다.

1. `3450b2a7` — 피드백 대상 태깅 기준을 정정했다(새 다중 대상 태깅 규칙).
   13회차에서 관측된 "이름이 없으면 전원 대상" 과다 태깅(포지션 특정 조언까지
   `addressed_to_all`로 묶이던 문제)을 겨냥한 수정이다.
2. `03b43616`("fix: fc-feedback 시트 이미지 번호 어긋남 수정") — 13회차까지
   남아 있던 `scan` 단계 시트 파일 번호 off-by-one 버그를 고쳤다.

이 회차의 모든 심사 패킷에는 `session.json`이 포함됐다 — 13회차에서
`session.json` 누락으로 채널명을 환각으로 오판해 재심사해야 했던 문제가 이번엔
없었다.

## 정성 점검

- **전원 대상 과다 태깅 해소.** `Cd7Kf3WpQ24`(풀백 수비 강의)에서 세 모델
  모두 이전엔 유닛 21~27개 전부가 `addressed_to_all`이었는데 이번엔 0개로
  줄고, 대신 전부 풀백 포지션 태그가 달렸다. sol의 `PIjy1eid3RU`도 이전엔
  40유닛 전부 전원 대상이었는데 이번엔 40유닛 중 13개로 줄었다. 13회차에서
  지적한 문제가 커밋 `3450b2a7`으로 해소됐다는 직접적인 증거다.
- **NUz 포지션 태그 붕괴(신규 발견).** 새 태깅 규칙 문구("지목된
  포지션('풀백은…')")가 "포지션 이름으로 지목된 조언"만 잡도록 좁아졌는데,
  NUz 코치는 포지션이 아니라 선수 이름으로 지적한다 — 그 결과 NUz 반복의
  포지션 태그 유닛 수가 13회차 9~14개에서 이번엔 0~2개로 무너졌고(opus는 3회
  모두 0개), 포지션 태그 F1도 약 0.1 수준으로 떨어졌다(opus는 0.0%). 위
  자동 점수 하락(세 모델 모두 3점 안팎)의 직접 원인이다. 커밋 `dda6d5f6`
  ("docs: fc-feedback 포지션 태그 기준 확장")으로 "포지션 태그 = 코치가
  이름으로 지목한 포지션 + 장면에서 호명된 팀원의 포지션 + 명단상 주 포지션
  폴백"으로 기준을 넓혀 고쳤다 — 15회차(NUz만, 3모델×3반복)에서 확인 예정이다.
- **세 모델 공통, 실수 자체를 짚는 볼드.** 심사에서 페널티·정지 장면 볼드가
  다음 행동이 아니라 "실수" 자체를 짚는다는 지적이 반복됐다 — 다만 사용자가
  이 유형은 허용 가능하다고 확인한 바 있다.
- **캡션이 일반적이다.** 캡션이 정확하긴 하지만 "위치 표시"처럼 일반적인
  문구에 머물러 장면 행동과 직접 연결되지 않는다는 지적이 반복됐다.

## 사용자 확인 필요

- **"관련:" 목록의 팀 간 명단 누수.** "관련:" 목록이 포지션 태그로부터
  자동 도출되는데, `Cd7Kf3WpQ24`(풀백 수비 강의)의 모든 풀백 유닛에 gold
  영상 팀(C.E.F.) 평가용 명단(`roster.cef.yaml`)의 팀원(예: 원전)이 걸린다
  — 13회차에서 확인한 것과 같은 팀 간 명단 오염이 이번엔 "코치" 지칭이
  아니라 "관련:" 목록 경로로 재현됐다.
- **"샘백" 명단 항목.** 13회차에 이어 이번에도 "샘백"이 포지션 "센터백"의
  ASR 오인식일 가능성이 반복 거론됐다 — 인명이 아니라 포지션명이 팀원으로
  잘못 등록됐을 수 있다.

## 결론

전원 대상 과다 태깅 수정(`3450b2a7`)은 목표대로 작동해 held-out 세 영상의
과다 태깅이 해소되고 held-out 심사 점수도 세 모델 모두 32~34점대로 고르게
올라왔다. 그런데 같은 수정이 NUz의 포지션 태그를 무너뜨리는 부작용을 냈다 —
NUz 코치가 포지션이 아니라 이름으로 지적하는 발화 패턴을 새 규칙이 놓치면서
세 모델 모두 자동 점수가 13회차 대비 3점 안팎 떨어졌다. gold NUz 총점 자체는
여전히 opus(85.14) > luna(82.94) > sol(81.65) 순서를 유지하지만, 이 순서
비교는 포지션 태그가 무너진 상태에서 나온 값이라 13회차와 직접 비교하기는
어렵다. 포지션 태그 기준을 넓힌 커밋 `dda6d5f6`으로 수정했고, 15회차에서
확인 예정이다.
