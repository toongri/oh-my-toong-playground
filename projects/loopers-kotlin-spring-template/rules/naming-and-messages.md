# 네이밍 판단 규칙

컴포넌트·메서드·변수·불리언 이름을 어떻게 지을지를 다루는 규칙이다. 문서를 열어 판단 기준과 안티패턴을 확인한다.

- `docs/implementation/naming-conventions.md` — **컴포넌트·메서드·변수·불리언 네이밍**: 네이밍 일관성이 필요한 이유, 컴포넌트 네이밍, 메서드 네이밍, 변수 네이밍, 불리언 네이밍, 안티패턴, 이런 생각이 들면 멈춰라(Critical Rules 발췌)

**관련 규칙**: 에러 메시지 표기는 `api-contract.md` rule의 `error-handling.md`에 있다.
